Comment cela fonctionne

  • Le portail genere une bi-cle RSA 2048 bits. La cle privee est chiffree par votre code : le serveur ne le conserve jamais.
  • A la signature, le code dechiffre la cle et appose une signature RSASSA-PSS/SHA-256 sur l'empreinte de l'acte.
  • Toute modification ulterieure de l'acte rend la verification negative.
  • Chaque acte signe porte un code et un QR code renvoyant a la page publique de verification.
  • Code perdu : revoquez la cle et generez-en une nouvelle. Les actes deja signes restent verifiables.
